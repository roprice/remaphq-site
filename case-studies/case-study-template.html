How I directed an AI agent through a complex production task, and what it reveals about the skills that matter in 2026

March 2026·Rowan Price·12 min read

Opening paragraph sets up the context. What was the task, why did it matter, what's at stake. Keep it concrete and skip the throat-clearing. The reader should know within two sentences whether this is relevant to them.

Second paragraph can establish the technical environment or constraints. Name the tools involved and the human/agent dynamic without over-explaining.

rowan

Before you start the full run, here are the updated specs. Let me know if you have any questions.

daniel (AI agent)

Got the updated spec. Noted these changes: categories split into browse-by-page vs keyword search, naming is now 1-indexed, "Health & Fitness" replacing previous variations.

No questions on the spec itself. It's clear.

vince

Daniel, what do you need from me in order to make this happen?

Specification precision Catching assumptions before they compound

Notice what's happening here. The agent confirmed the spec changes correctly, but I haven't told it to start yet. This is intentional. I need to see that the agent parsed the spec the way I intended before it burns through 400 API calls. If there's a misunderstanding, it costs me 30 seconds now versus an hour of wrong output later.

This is the difference between prompting and specification management. Prompting is getting the first response right. Specification management is making sure the agent stays aligned across a multi-step workflow.

With the spec confirmed, the next question was infrastructure. Where do 400 images go? The agent proposed several options, each with different tradeoffs.

daniel (AI agent)

My recommendation: OneDrive if Vince has it set up, otherwise local-then-transfer.

rowan

We're going to have you store the images directly on the Denmori server as you go. To set that up, I need your public SSH key.

Trust & security design Access control as a design decision

The agent suggested OneDrive, Google Drive, local storage. I chose none of them. Instead, I gave it SSH access to a dedicated server with a dedicated user, scoped to a single directory. This is access control thinking applied to an AI agent: minimum viable permissions, no credential sharing, auditable path.

# Phase 1: App Store screenshot sourcing We need to source reference images from the Apple App Store. These will be used as visual references for an AI image generation system. ## What we need - 20 categories, 5 apps per category, 4 screenshots per app - Full resolution (request 1290x2796, accept native max) - Naming: {category}/set{n}_image{n}.jpg (1-indexed)
The spec as a living document

This is the final version of the spec. It was revised twice during the conversation based on what we learned from the API test. The first version assumed composite strip images existed as downloadable assets. They don't. The second version assumed we could request arbitrary resolutions. We can, but the CDN caps at native upload size. Each revision was informed by a test, not by guessing.

Closing section ties the specific decisions back to the broader skill framework. What patterns transfer to other contexts. What you'd do differently next time. Keep it short.
